Murder Mystery

A social-deduction minigame plugin for Paper servers.

Java server plugin•Declared API: 1.21

ABOUT THIS PLUGIN

Find the murderer. Survive the round.

Murder Mystery is a round-based minigame where players can take on different roles, collect coins, and unlock weapon cosmetics through crates. Match settings and weapon/crate options are configurable in the plugin's config file.

Features listed in the included configuration

  • Round settings including minimum players, countdowns, and round length
  • Coin spawning and configurable coin rewards
  • Knife and gun weapon collections with rarity tiers
  • Knife, gun, mystery, and godly crate definitions
  • Configurable crate prices and rarity weights
  • Admin solo-test option for testing games

Before installing

This release includes a plugin.yml declaring the name MurderMystery, version 1.0.0, main class com.mm2.MM2Plugin, and the mm2.admin permission. The plugin declares API version 1.21. Test it on a backup first and confirm compatibility with your server build.

Important: The website describes settings found in the JAR's configuration; it does not guarantee every feature has been fully tested. Verify behavior on a test server before using it publicly.
