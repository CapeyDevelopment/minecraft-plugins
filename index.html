QUICK START

Install in a few steps.

01

Download

Open a plugin page, read the details, then use its download button.

02

Upload

Stop your Paper server and put the downloaded .jar in the server's plugins folder.

03

Restart

Start the server again and check the console for plugin messages. Read each plugin's setup instructions.

Tip: Back up your server before installing new plugins. Always check compatibility with your exact Minecraft/server version.
